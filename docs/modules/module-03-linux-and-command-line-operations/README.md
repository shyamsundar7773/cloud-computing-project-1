## Syllabus scope

### Phase 1A.3 - SERVER PRACTICE ENVIRONMENT

Set up a safe Linux practice environment using WSL or another suitable local environment; create application folders and sample logs; practice file operations and process inspection; simulate basic server issues.
### Phase 1B.3 - LINUX TECHNICAL LEARNING

Linux architecture/distributions, terminal and shell, filesystem hierarchy and paths, files/directories, permissions and ownership, users/groups, processes/services, disk/memory, logs, SSH, package management and shell scripting. Practice the syllabus commands: pwd, ls, cd, mkdir, touch, cp, mv, rm, cat, less, head, tail, grep, find, wc, chmod, chown, ps, top, kill, free, df, du, systemctl, journalctl.
### Phase 1C.3 - BUSINESS UNDERSTANDING

Why Linux servers are used; application hosting, administration, monitoring, log investigations, permissions, disk space, service failures, operational support and incident management.
### Phase 1D.3 - INTERVIEW PREPARATION

Linux/filesystem/permission/process questions; command identification; practical terminal assessment; investigate an unavailable application through logs, processes and disk usage.
