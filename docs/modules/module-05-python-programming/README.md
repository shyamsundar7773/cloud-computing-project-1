## Syllabus scope

### Phase 1A.5 - PYTHON DATA PROCESSING PROJECT

Build a utility to read order CSV and JSON, validate customer/product records, clean invalid data, handle missing values, summarize and write processed output, record errors and log runs.
### Phase 1B.5 - PYTHON TECHNICAL LEARNING

Installation/interpreter, variables/types/conversion, conditions/loops, functions/scope, collections/strings, file handling, CSV/JSON, exceptions, modules/imports, virtual environments, pip/libraries, HTTP/APIs, logging, environment variables, debugging and basic unit testing.
### Phase 1C.5 - BUSINESS UNDERSTANDING

Automation versus manual work; data cleaning, validation rules, duplicates, error handling, quality, reusable automation, operational efficiency and audit logs.
### Phase 1D.5 - INTERVIEW PREPARATION

Python/data types/code output, functions, loops, collections, file handling, exceptions, CSV/JSON practical work, timed coding and debugging scenarios.
