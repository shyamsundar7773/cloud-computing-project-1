## Syllabus scope

### Phase 1A.8 - CLOUD OPERATIONS PROJECT

Connect selected components to storage; configure basic access; monitor health/logs, configure basic alerts where practical, simulate failures and document recovery/cleanup.
### Phase 1B.8 - TECHNICAL LEARNING

Resource/identity/RBAC and least privilege; storage/network permissions and secrets; metrics/logs/alerts/health; backup/restore/retention/recovery; incident troubleshooting and change management. Docker fundamentals and CI/CD, rollback, IaC/Terraform awareness.
### Phase 1C.8 - BUSINESS UNDERSTANDING

Production support, incidents, SLA/SLO awareness, availability, security incidents, access reviews, cost management, continuity, root-cause analysis, escalation and operations documentation.
### Phase 1D.8 - INTERVIEW PREPARATION

Operations, IAM/security, monitoring, backup/recovery, Docker/CI-CD; permission denied, unavailable application, storage access, unexpected billing and incident scenarios.
