## Syllabus scope

### Phase 1A.6 - PROJECT INTEGRATION

Maintain source, branches, commits and organized folders; integrate a sample REST API, fetch/process external data, save results and document the integration.
### Phase 1B.6 - TECHNICAL LEARNING

Git commands/workflows, repositories, branches, pull requests, conflicts, ignore rules and code review. REST endpoints/resources, HTTP methods, JSON, headers/status codes, authentication concepts, API keys/tokens, OAuth awareness, pagination, rate limits, retries, timeouts, errors and secret management.
### Phase 1C.6 - BUSINESS UNDERSTANDING

Developer, tester and operations responsibilities; payment/shipping/third-party integrations; data exchange, vendor failures, change management and collaboration.
### Phase 1D.6 - INTERVIEW PREPARATION

Git and REST/API questions; methods, JSON, practical integration, Git conflict/API failure scenarios and secure credential handling.
