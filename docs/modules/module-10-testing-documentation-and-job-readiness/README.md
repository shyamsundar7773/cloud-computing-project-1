## Syllabus scope

### Phase 1A.10 - FINAL PROJECT HARDENING

Review architecture; test components and inputs/outputs; test failures; improve errors/logging; organize source; prepare documentation, final architecture, demo and limitations.
### Phase 1B.10 - TESTING AND DELIVERY TECHNICAL LEARNING

Functional/unit/integration and regression awareness; test cases and expected results; debugging/logging; configuration and environment variables; secret hygiene; deployment stages, releases, rollback, documentation, reporting/dashboard awareness.
### Phase 1C.10 - PROFESSIONAL WORKPLACE UNDERSTANDING

IT teams, tickets, requirements, task assignment/status, incident escalation, collaboration, technical documentation/handover, root-cause analysis and business-team communication.
### Phase 1D.10 - FINAL INTERVIEW PREPARATION

Integrated technical/SQL/Python/Linux/network/cloud/API/data assessments; structured answers, troubleshooting, architecture/project presentation, HR, teamwork, problem solving, communication, mock interview and readiness scorecard.
