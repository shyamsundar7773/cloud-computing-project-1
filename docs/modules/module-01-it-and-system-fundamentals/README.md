## Syllabus scope

### Phase 1A.1 - PROJECT FOUNDATION

Introduce the fictional online retailer; define the business problem, users, objectives, scope, and major system components; document the project and establish its repository structure.
### Phase 1B.1 - COMPUTER AND IT FUNDAMENTALS

Computer hardware/software; CPU, RAM, storage; operating systems, processes, services, filesystems; client-server, frontend/backend, applications, databases, APIs, servers, virtualization, data centers, development/testing/production environments, and application lifecycle. Include practical demonstrations.
### Phase 1C.1 - BUSINESS UNDERSTANDING

Online retail operations; customers, products, orders, payments, shipments, departments and employee responsibilities; order lifecycle, customer-facing workflow, and how departments use IT.
### Phase 1D.1 - INTERVIEW PREPARATION

Computer fundamentals and OS questions; client-server; definitions and structured explanations; explain the customer order journey and the project architecture.
