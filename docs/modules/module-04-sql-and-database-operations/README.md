## Syllabus scope

### Phase 1A.4 - RETAIL DATABASE PROJECT

Model Customers, Products, Orders, Order_Items, Payments and Shipments; create relationships, keys and constraints; add sample business data, validation and business queries.
### Phase 1B.4 - SQL TECHNICAL LEARNING

Relational fundamentals, tables/rows/columns, types, keys/constraints, SELECT/filter/sort/distinct/limit/NULL, DML, aggregates/grouping, joins, subqueries, CTEs, CASE, set operations, window functions, normalization, indexes/performance, transactions, ACID, backup/recovery. PostgreSQL is the initial practice database.
### Phase 1C.4 - BUSINESS UNDERSTANDING

Customer/product/order/payment/shipment data; revenue, gross/net sales, average order value, retention, product performance, daily sales, business metrics, data quality and reporting needs.
### Phase 1D.4 - INTERVIEW PREPARATION

SQL and query-output questions; joins, grouping, subqueries, CTEs, window functions, timed SQL, business-query interpretation and database troubleshooting.
