## Syllabus scope

### Phase 1A.7 - CLOUD ENVIRONMENT PROJECT

Design cloud architecture; understand subscriptions, resource groups, regions, naming, provisioning, permissions and billing; create only approved basic resources after cost/security review.
### Phase 1B.7 - CLOUD TECHNICAL LEARNING

Cloud models and shared responsibility; regions/zones, scalability/elasticity/availability; compute, storage and databases; networking; identity, Entra ID/RBAC; monitoring, backup/recovery, pricing, billing and cleanup. Introduce Azure VMs, Blob/Storage Accounts, Azure SQL, VNet, Entra ID, RBAC, Monitor and Data Factory.
### Phase 1C.7 - BUSINESS UNDERSTANDING

Cloud adoption and migration, on-premises comparison, infrastructure ownership, operations, cost optimization, continuity, security, availability, disaster recovery and managed services.
### Phase 1D.7 - INTERVIEW PREPARATION

Cloud models, Azure services, regions/zones, storage/compute, IAM/RBAC, shared responsibility, pricing and service-selection scenarios.
