## Syllabus scope

### Phase 1A.9 - END-TO-END DATA PIPELINE PROJECT

Collect CSV/API data; ingest and retain raw files; validate, clean, transform and load into a database; create business-ready outputs; log, handle failures and make runs repeatable using Python, SQL, PostgreSQL and cloud services where practical.
### Phase 1B.9 - DATA ENGINEERING TECHNICAL LEARNING

Data lifecycle/ingestion, ETL/ELT, batch and streaming awareness, lakes/warehouses/operational DBs, CSV/JSON/Parquet awareness, data models/facts/dimensions/star schema, quality dimensions, incremental loading/watermarks/idempotency, orchestration/scheduling/dependencies/retries/monitoring. Azure Data Factory/ADLS/Azure SQL; Fabric, Databricks, Spark, PySpark and Kafka awareness.
### Phase 1C.9 - BUSINESS UNDERSTANDING

Business data use and reporting; BI and decisions; ownership, lineage, governance, quality, reporting delays, duplicate records, incorrect metrics, warehouse needs and pipeline failure impact.
### Phase 1D.9 - INTERVIEW PREPARATION

ETL/ELT, warehouses/lakes, batch/streaming, data quality/modeling, pipeline explanations, SQL/Python practice, validation and failed-pipeline scenarios.
