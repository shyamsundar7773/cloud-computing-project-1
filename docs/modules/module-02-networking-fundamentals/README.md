## Syllabus scope

### Phase 1A.2 - NETWORK CONNECTIVITY PROJECT

Map the user-to-application path, including frontend, backend and database communication; create a network-flow diagram; perform and document connectivity checks.
### Phase 1B.2 - NETWORKING TECHNICAL LEARNING

Networking fundamentals; IP/public/private addressing, IPv4, basic subnet concepts, DNS, domain names, TCP/UDP, ports, HTTP/HTTPS, TLS purpose, client-server, routers, switches, firewalls, NAT, VPN, network security and basic cloud networking. Practice ipconfig/ifconfig, ping, nslookup, tracert/traceroute, curl, netstat/ss.
### Phase 1C.2 - BUSINESS UNDERSTANDING

How users access applications; DNS, firewalls and ports; network security, availability, latency, connectivity failures and business impact.
### Phase 1D.2 - INTERVIEW PREPARATION

Networking and IP questions; DNS; TCP vs UDP; HTTP vs HTTPS; common ports; practical DNS troubleshooting and website connectivity failure scenario.
